# SwiftLM - On-Device LLM Toolkit for Swift

SwiftLM is a Swift library and CLI for running LLMs and embedding models on Apple devices using CoreML. It supports HuggingFace model export, grammar-constrained JSON generation, text embeddings, and compatibility with Apple's FoundationModels framework.

## Core Components

### 1. CoreMLLanguageModel

The main interface for running CoreML LLMs:

```swift
import SwiftLM

// Load a model
let model = try CoreMLLanguageModel.loadCompiled(url: modelURL)

// Create a session with a system prompt
let session = await model.makeSession(systemPrompt: "You are a helpful assistant.")

// Stream responses
for await token in await session.infer(prompt: "What is 2+2?") {
    print(token, terminator: "")
}

// JSON-constrained generation
let result: MyType = try await session.infer(prompt: "Generate user data", as: MyType.self)
```

### 2. @JSONSchema Macro

Generates JSON schema metadata and grammar rules for structured output:

```swift
@JSONSchema
public struct UserProfile: Codable, JSONSchemaConvertible {
    @SchemaGuide("User's full name", .maxLength(100))
    var name: String

    @SchemaGuide("Age in years", .range(0...150))
    var age: Int

    @SchemaGuide("List of hobbies", .count(1...10))
    var hobbies: [String]

    @SchemaGuide("Preferred contact method", .anyOf(["email", "phone", "mail"]))
    var contactMethod: String

    @SchemaGuide("Internal ID - not generated by LLM", .skip)
    var id: String = UUID().uuidString
}
```

### 3. @SchemaGuide Constraints

| Constraint | Usage | Description |
|------------|-------|-------------|
| `.maxLength(Int)` | `@SchemaGuide("desc", .maxLength(100))` | Max string length |
| `.range(ClosedRange<Int>)` | `@SchemaGuide("desc", .range(1...100))` | Integer range |
| `.doubleRange(ClosedRange<Double>)` | `@SchemaGuide("desc", .doubleRange(0.0...1.0))` | Double range |
| `.count(ClosedRange<Int>)` | `@SchemaGuide("desc", .count(1...10))` | Array element count |
| `.anyOf([String])` | `@SchemaGuide("desc", .anyOf(["a", "b"]))` | Enum-like string options |
| `.skip` | `@SchemaGuide("desc", .skip)` | Skip generation, use default |

### 4. FoundationModels Compatibility

Types annotated with `@JSONSchema` automatically conform to Apple's `Generable` protocol (macOS 26+/iOS 26+):

```swift
@JSONSchema
public struct TripIntent: Codable, JSONSchemaConvertible, Sendable {
    @SchemaGuide("User interests", .count(1...10))
    var interests: [String]

    @SchemaGuide("Reasoning about the trip")
    var reasoning: String
}

// Works with both CoreMLLanguageModel and Apple's FoundationModels
let intent: TripIntent = try await languageModel.structuredAsk(
    system: "Parse user intent",
    input: userQuery,
    output: TripIntent.self
)
```

### 5. LanguageModel Protocol

Unified interface for different LLM backends:

```swift
public protocol LanguageModel: Sendable {
    associatedtype Conversation: LanguageModelConversation

    func startConversation(systemPrompt: String) async -> Conversation
    func structuredAsk<Input, Output>(system: String, input: Input, output: Output.Type) async throws -> Output
}
```

Implementations:
- `CoreMLLanguageModel` - Custom CoreML models (Qwen, Llama, Mistral, DeepSeek)
- `FoundationLanguageModel` - Apple's on-device models (macOS 26+)

### 6. CoreMLEmbeddingModel

Text embedding model for semantic search, similarity, and clustering:

```swift
import SwiftLM

// Load an embedding model
let model = try CoreMLEmbeddingModel.load(url: embeddingModelURL)

// Embed text
let embedding = try await model.embed(text: "Hello world")  // [Float] of dimension 768

// Batch embed
let embeddings = try await model.embed(texts: ["Hello", "World"])

// Semantic similarity
let similarity = try await model.similarity("cat", "dog")  // 0.0-1.0

// Semantic search
let results = try await model.search(
    query: "machine learning",
    documents: ["AI research", "cooking recipes", "neural networks"],
    topK: 2
)
// Returns: [(index: 2, score: 0.85), (index: 0, score: 0.72)]
```

**Supported pooling strategies:**
- `mean` - Average of all token embeddings (default)
- `cls` - Use [CLS] token embedding
- `last` - Use last token embedding

## CLI Tool

### Export HuggingFace Models to CoreML

```bash
# Causal LMs (text generation)
swiftlm export meta-llama/Llama-3.2-1B-Instruct
swiftlm export Qwen/Qwen2.5-1.5B-Instruct --quantize int4 --output-dir ./models
swiftlm export mistralai/Mistral-7B-Instruct-v0.3 --max-context 4096

# Embedding models
swiftlm export nomic-ai/nomic-embed-text-v1.5 --embedding
swiftlm export BAAI/bge-small-en-v1.5 --embedding --pooling cls
swiftlm export intfloat/e5-small-v2 --embedding --quantize int4
```

### Test Models

```bash
# Test causal LM
swiftlm test ./models/Qwen2.5-1.5B-Instruct.mlpackage --prompt "Hello!"

# Test embedding model
swiftlm embed ./models/nomic-embed-text-v1.5_Embedding.mlpackage \
    --text "Hello world" \
    --text "Greetings planet" \
    --similarity

# Semantic search
swiftlm embed ./models/bge-small-en-v1.5_Embedding.mlpackage \
    --query "machine learning" \
    --documents "AI research,cooking recipes,neural networks"
```

## Supported Architectures

### Causal LMs (Text Generation)

| Architecture | Models | Notes |
|--------------|--------|-------|
| LlamaForCausalLM | Llama 3.x, Llama 2 | Works on CPU+GPU |
| MistralForCausalLM | Mistral 7B | Works on CPU+GPU |
| Qwen2ForCausalLM | Qwen 2.5 | **Requires GPU** (CPU produces NaN) |
| Qwen3ForCausalLM | Qwen 3 | **Requires GPU** |
| DeepseekV3ForCausalLM | DeepSeek models | **Requires GPU** |

### Embedding Models

| Architecture | Models | Pooling |
|--------------|--------|---------|
| BertModel | BERT, RoBERTa, DistilBERT | CLS |
| XLMRobertaModel | E5, BGE, multilingual models | Mean/CLS |
| NomicBertModel | Nomic Embed | Mean |

## Grammar-Constrained Decoding

SwiftLM uses GBNF grammars to ensure valid JSON output. The grammar is automatically generated from `@JSONSchema` types:

1. Schema description is injected into the prompt
2. Grammar rules constrain token generation to valid JSON
3. Output is parsed and validated against the schema

```swift
// The Session handles all of this automatically
let result: MyType = try await session.infer(prompt: "Generate data", as: MyType.self)
```

## Key Implementation Notes

### KV Cache

Models use stateful KV cache for efficient autoregressive generation:
```
Shape: (num_layers, batch_size, num_kv_heads, max_context_size, head_dim)
```

### Compute Units

Some models require GPU compute units:
```swift
let config = MLModelConfiguration()
config.computeUnits = .cpuAndGPU  // Required for Qwen/DeepSeek
let model = try MLModel(contentsOf: url, configuration: config)
```

### Causal Mask

The exported CoreML models handle mask slicing internally. Swift passes a full square mask `[1, 1, N, N]` and the model slices it to `[1, 1, q_len, kv_len]`.
